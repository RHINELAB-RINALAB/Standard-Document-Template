## RHINELAB Document Templates

This is the note to specify and making use of templates, notes and all that would be used by members of RHINELAB. In specificity, there are some notes that would deliberately be used as baseline requirement in contexts, like research topics, or personal statements. Currently we have (not all up here), 
- `TEMP-1`: Personal Statement document template. 
- `TEMP-2`: Research Topic document template, for code `RT`. 
- `TEMP-3`: Proposal document template, for sub-code document `-PROP`. 
- `TEMP-4`: Lab Structure Proposal document template, for **administration-wise** documents. 

> [!note] 
> ### Requirement of the template. 
> Minimally, it uses `LaTeX` for writing those templates, so your task is to be familiar with them. If you found any `package` to be missing or would be recommended to have, please make an **issue** for proposal.
